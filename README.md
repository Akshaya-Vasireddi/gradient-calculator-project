# 🎨 Gradient Calculator

An interactive and visually appealing Gradient Calculator built using HTML, CSS, and JavaScript.  
This project allows users to generate smooth gradient backgrounds instantly and view the CSS code in real time.

---

## 🚀 Project Overview

The Gradient Calculator helps users experiment with different color combinations and create beautiful gradient effects for websites, portfolios, and UI designs.

It is designed with a clean interface and dynamic functionality to provide a simple user experience.

---

## ✨ Features

✅ Generate linear gradient backgrounds  
✅ Real-time gradient preview  
✅ Instant CSS code generation  
✅ Easy-to-use interface  
✅ Responsive design  
✅ Dynamic color updates using JavaScript  

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
